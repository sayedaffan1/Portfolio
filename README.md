# 3D Interactive Portfolio

A modern, responsive, and interactive personal portfolio website built with React, Vite, and 3D web graphics. This portfolio showcases projects, skills, and experience with a dynamic user interface.

## 🚀 Features

* **3D Background:** Interactive 3D graphics rendered dynamically in the background.
* **Component-Based Architecture:** Built modularly using React components (Navbar, Background3D, etc.).
* **Fast Performance:** Powered by Vite for lightning-fast HMR (Hot Module Replacement) and optimized production builds.
* **Responsive Design:** Optimized across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

* **Framework:** [React](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Graphics:** Three.js / WebGL
* **Styling:** CSS3 / Custom Modular CSS
